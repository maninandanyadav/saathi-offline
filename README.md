# SAATHI

A private AI companion that runs entirely on your own computer.
No cloud, no account, no API key. Your conversations never leave this machine.

SAATHI is a companion, not a replacement for real people, friends, family,
doctors, therapists, or emergency services.

## Running it

    .\venv\Scripts\python.exe -m uvicorn backend.main:app --reload

Then open http://127.0.0.1:8000
